# Jonathan Mwanza — Software Engineer Portfolio

A responsive portfolio built with HTML, CSS, and vanilla JavaScript. It follows the submitted dark, gold, and blue tech-inspired design without requiring a build step or third-party JavaScript libraries.

## Run locally

Open `index.html` in a modern browser, or serve the repository with any static file server.

## Personalize

- Add your portrait as `images/jonathan-mwanza.jpg`; the designed initials placeholder appears until the image is present.
- Review the project examples, skill indicators, and portfolio statistics in `index.html` and adjust them to match your current work.
- Update the services and introductory copy to reflect what you offer.
- Your email, call, and WhatsApp details are in the Contact section.

## Included interactions

- Responsive navigation with active-section highlighting.
- Light/dark theme switch and animated software-engineering role text.
- A dependency-free animated canvas sphere and scroll-triggered skill/stat reveals.
- Project and service links that prefill the WhatsApp contact form.
- Contact form validation that prepares a WhatsApp message for review before sending.
- Scroll progress, back-to-top, keyboard controls, and reduced-motion support.
